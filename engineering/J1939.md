Standard defined by SAE for communication in heavy duty machines.
Based on [[CAN]], gives a set of rules to interpret signals.
Speed at 250 and 500 kBps.

### Arbitration Field
P = Priority. 0 is highest and 7 is lowest.
R = Reserved.
DP = Data Page.
PF (PDUF) = Protocol Data Unit Format. Message is destination specific (< 240) or
broadcast (> 240)
PS or PDUS = Protocol Data Unit Specific. Destination or group extension.
SA = Source Address. 
PGN = Parameter Group Number (PDUF + PDUS). Uniquely identifies type of message.

### Data field
Diagnostic messages (DM): Result from testing on vehicles, reports history and fault detection from the former.
SPN = Suspect Parameter Number. Describes the parameter in the data bytes. (DM24)
DTC = Diagnostic Trouble Code: Represents a faulty property in the system.
DM1 = Provide DTC's
FMI = Failure Mode Indicator: 31 total, f.e:
- FMI = 1, then Data valid but below normal operational range.
- FMI = 2, Data erratic or intermittent. 
CM = Conversion method: Makes reference to an old structure.
OC = Ocurrence count.
